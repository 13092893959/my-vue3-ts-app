# 百万撤离管理系统 - 快速开始

## 🚀 三步启动系统

### 第1步：双击运行

找到 `start.bat` 文件，双击运行。

位置：`backend/start.bat`

### 第2步：等待启动

脚本会自动：

- ✅ 检查Node.js环境
- ✅ 安装必要依赖（首次运行）
- ✅ 初始化数据文件（首次运行）
- ✅ 启动服务

看到以下提示表示成功：

```
====================================
  服务地址: http://localhost:3000
  数据目录: D:/data/baiwancheli
  按 Ctrl+C 停止服务
====================================
```

### 第3步：访问系统

打开浏览器访问：

```
http://localhost:3000
```

默认账号：

- 用户名：`admin`
- 密码：`123456`

## ❓ 遇到问题？

### 问题1：提示"未检测到Node.js"

**解决：** 安装Node.js

- 下载地址：https://nodejs.org/
- 选择LTS版本
- 安装后重启命令行

### 问题2：端口3000被占用

**解决：** 修改端口

1. 编辑 `server/index.js`
2. 修改第7行：`const port = 3001`
3. 重新启动

### 问题3：无法访问系统

**检查清单：**

- [ ] 服务是否已启动（查看命令行窗口）
- [ ] 浏览器地址是否正确（http://localhost:3000）
- [ ] 防火墙是否阻止（临时关闭测试）
